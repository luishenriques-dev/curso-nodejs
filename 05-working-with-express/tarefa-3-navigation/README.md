# Tarefa 3 — Navigation

**Secção 5 — Working with Express.js**

> **Em resumo:** uma app Express com **duas páginas HTML** (`/` e `/users`) e **ficheiros estáticos** (CSS ou JS) servidos a partir de uma pasta pública.

---

## 📋 Enunciado

1. Cria um projeto **npm** e instala o **Express.js** (e o **nodemon**, se quiseres).
2. Cria uma app Express que serve **dois ficheiros HTML** (à tua escolha e com o teu conteúdo), um para **`/`** e outro para **`/users`**.
3. Adiciona ao projeto alguns ficheiros **estáticos** (`.js` ou `.css`) que pelo menos um dos teus ficheiros HTML vá buscar.

---

## 🧪 Como testar

| Teste | Resultado esperado |
|---|---|
| Abrir `localhost:3000` | Aparece a primeira página HTML |
| Abrir `localhost:3000/users` | Aparece a segunda página HTML |
| Ver a página com o CSS ou JS | O estilo ou o script estão a funcionar |
| Separador **Network** das ferramentas de programador | O ficheiro `.css` ou `.js` carrega com o código **200** |
