# 24. Module Introduction

**Secção 3 — Understanding the Basics**

> **Em resumo:** a secção 3 começa os **fundamentos do Node.js**, a partir do zero.

---

## O que se vai aprender nesta secção

1. **Como a web funciona.** Uma revisão rápida, para perceber o papel do Node quando se constrói um servidor.
2. **Criar um servidor Node.js**, com o core module `http`, e correr código quando chegam pedidos.
3. **Requests e responses:** receber os pedidos, ler os dados que trazem, e enviar respostas.
4. **Core modules**, como o `fs`, para trabalhar com ficheiros.
5. **Código assíncrono e o event loop:** como o Node se mantém rápido e nunca bloqueia.
