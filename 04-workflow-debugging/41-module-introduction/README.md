# 41. Module Introduction

**Secção 4 — Improved Development Workflow and Debugging**

> **Em resumo:** depois de trabalhar com o Node "à mão" na secção 3, esta secção mostra como **tornar o desenvolvimento mais fácil e rápido** e como **depurar** (*debug*) as aplicações.

---

## O que se vai aprender nesta secção

1. **Acelerar o desenvolvimento:** o npm, os scripts e pacotes que facilitam o trabalho.
2. **Depurar:** encontrar e perceber os erros, e usar ferramentas para ver o que se passa dentro do código enquanto ele corre.
