# 95. Module Introduction

**Secção 7 — The Model View Controller (MVC)**

> **Em resumo:** esta secção é sobre **organizar o código** com um padrão chamado **MVC**. Não é só dividir em ficheiros: é separar o código pelo **papel** que cada parte tem na app.

---

## O que vem nesta secção

| Tema | O que é |
|---|---|
| **O padrão MVC** | Uma forma de separar o código em **três papéis**: Model, View e Controller |
| **Aplicá-lo ao projeto** | Reorganizar a loja que já existe segundo o MVC |
| **Avançar com a loja** | Continuar a construir a loja online, já com a nova organização |

---

## A ideia

Até aqui, o código foi crescendo **onde calhava**. Por exemplo, as rotas guardam os produtos, decidem a página a mostrar e preparam os dados, tudo no mesmo sítio.

O MVC diz que **cada parte do código deve ter um só papel**. A aula seguinte explica quais são os três.

> 💡 Já tens um bocado de MVC sem saber: a pasta **`views`** (aula 69) é o **"V"**.

---

## ✅ A reter

- **MVC** = um padrão para **separar o código pelo papel** de cada parte.
- Nesta secção, o projeto da loja é **reorganizado** segundo o MVC, e continua a crescer.
