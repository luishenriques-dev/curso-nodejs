## Recursos

- **Sessões**: [What is a session in a Web Application (Quora)](https://www.quora.com/What-is-a-session-in-a-Web-Application)
- **Cookies**: [HTTP Cookies (MDN)](https://developer.mozilla.org/en-US/docs/Web/HTTP/Cookies)
- **express-session** (documentação oficial): [github.com/expressjs/session](https://github.com/expressjs/session)

> 💡 A documentação do MDN é a mais fiável para cookies. Para o `express-session`, a documentação oficial no GitHub explica todas as opções (`cookie`, `store`, `resave`, `saveUninitialized`).
