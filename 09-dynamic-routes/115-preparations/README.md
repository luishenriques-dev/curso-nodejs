## As duas opções do professor

| Opção | Para quem | O que fazer |
|---|---|---|
| **Snapshot** (o projeto completo) | Quem **saltou a secção 8** ← **o meu caso** | Descarregar o zip do snapshot e usá-lo como projeto |
| **Ajustes** (só os ficheiros que mudaram) | Quem fez a secção 8 | Juntar os ficheiros do zip de ajustes ao seu projeto |

> ⚠️ O professor é claro: **se saltaste a secção 8, usa sempre o snapshot**.

---

## O que o zip de ajustes tem (só para referência)

| Ficheiro | Para onde vai |
|---|---|
| `main.js` | **`public/js/`** (pasta nova) |
| `main.css`, `product.css` | **`public/css/`**, substituindo os que existem |
| As **views** | **`views/`**, substituindo as que existem |

O snapshot já traz tudo isto.

---

## Como usar o snapshot

1. Descarrega o zip do snapshot, anexado à aula 116 do Udemy.
2. Extrai-o e copia o conteúdo para a pasta desta aula (`115-preparations`).
3. Corre **`npm install`** na pasta: o snapshot não traz a `node_modules`.
4. Corre **`npm start`** e confirma que a loja abre.

> 💡 Quando houver algum problema mais à frente, o snapshot também serve para **comparar** com o meu código.
