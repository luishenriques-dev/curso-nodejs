# 270. Module Introduction

**Secção 16 — Sending Emails**

> **Em resumo:** neste módulo aprendemos a enviar emails a partir de uma aplicação Node. Vamos usar um pacote que trata do envio e, no fim, enviar um email quando o registo de um utilizador for bem sucedido.

---

## 1. Porque é que precisamos de emails

O envio de emails é comum em aplicações web. Exemplos:

- Confirmar o registo de um utilizador.
- Recuperar a password (vai ser o próximo passo depois deste módulo).
- Avisar sobre uma encomenda.

> 🧥 **Analogia do correio:** a tua aplicação escreve a carta, mas quem a entrega é um serviço de correio. O Node e o Express preparam a mensagem, e o pacote que vamos usar trata da entrega.

---

## 2. O que vamos fazer

1. Perceber como funciona o envio de emails numa aplicação Node.
2. Ver o papel do Node.js e do Express nesse processo.
3. Instalar um pacote para enviar emails.
4. Enviar um email quando um utilizador se regista com sucesso.

---

## ✅ A reter

- Enviar emails é uma tarefa comum em aplicações web.
- Neste módulo, o email de boas-vindas é enviado depois do registo.
- O envio de emails é a base para a recuperação de password.
